## Direct SNN Work

1. **"What is better: having neurons spike only once, or multiple times?"** (2026)
   - arXiv:2603.13478
   - Shows both approaches are computationally equivalent
   - Multi-spike more expressive per neuron, but not per layer

2. **"causal pieces"** (2025)
   - arXiv:2504.14015
   - Framework for analysing causal structure in SNNs
   - Can identify which neurons/spikes contribute to decisions

3. **Comment on training SNNs** for Physics Magazine (APS)
   - https://physics.aps.org/articles/v18/5

4. **Brennpunkt article** for Physik Journal (DPG, April 2025)
